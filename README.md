# Agentic AI Reflection Portfolio

A hands-on learning portfolio exploring how AI agents can improve their outputs through **reflection, execution feedback, and external evidence**.

I'm building these projects to provide a practical understanding of Agentic AI and explore how these techniques can support reliable, risk-aware AI systems.

## Projects

### Project 1: AI Data Analyst with Reflection
**Status:** In progress

An AI agent that generates SQL queries, executes them against a sample database, evaluates the results, and attempts to improve its query using feedback.

**Key learning objectives**
- SQL generation using an LLM
- Reflection and iterative improvement
- Using execution results as external feedback
- Testing outputs against expected answers
- Measuring when reflection improves correctness

### Project 2: AI Model Risk Review Agent
**Status:** Planned

A prototype that assesses a hypothetical AI or model-risk scenario, incorporates external evidence, and revises its initial assessment.

**Key learning objectives**
- Evidence-based risk assessment
- Identifying gaps in controls and documentation
- Revising assessments when new evidence becomes available
- Evaluating the quality and consistency of AI-generated assessments
- Understanding the limitations of AI-assisted risk governance

## Tools and Technologies

- Python and Jupyter Notebook
- Anthropic Claude API
- SQL and SQLite
- Reflection and external-feedback workflows
- GitHub for version control and project documentation

## Learning Approach

Each project will document the problem, methodology, experiments, results, limitations, and key lessons learned. The focus is not only on making an AI agent work, but also on evaluating whether its outputs are correct and reliable.

## Important Note

These projects are for educational and experimental purposes. The model-risk review agent is a prototype and is not intended to replace independent validation, human judgment, or formal risk approval.
